# Sicherheitsrichtlinie

Bitte veröffentliche mögliche Sicherheitslücken nicht als öffentliches Issue.

Nutze stattdessen im GitHub-Repository unter **Security → Advisories → Report a vulnerability** die private Sicherheitsmeldung. Beschreibe dort möglichst genau:

- die betroffene Version,
- die notwendigen Schritte zur Reproduktion,
- die erwartete und tatsächliche Auswirkung.

Zugangsdaten, Backup-Codes, Datenbanken oder andere persönliche Daten dürfen nicht an öffentliche Issues angehängt werden.
